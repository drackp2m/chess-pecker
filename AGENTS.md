# CLAUDE.md

Guidance for any coding agent working in this repository.

## Hard rules

- **NEVER run tests, linters, builds or the app.** No Vitest, no `pnpm lint`/`lint:fix` (nor ESLint/Prettier/Stylelint directly), no `ng serve`/`nest start`/`build`, no installing browsers to "see the page". The user runs and verifies everything.
- **Never commit.** The user makes every commit. If asked for a message, propose it as `<emoji> <type>: <subject>` (subject 10–75 chars, header ≤100; ✨ feat, 🐛 fix, ♻️ refactor, 🎨 style, 🧪 test, 📚 docs, 🚀 perf, 🏗️ build, 💻 ci, 🎒 chore, ⏪ revert) and **never add a `Co-Authored-By` trailer for yourself.**
- **Never add comments, docstrings or JSDoc** to generated code, unless explicitly asked.
- **Never hand-write or edit a migration** — change the entity under `apps/api/src/module/**/*.entity.ts` and the user generates the migration.
- **Never touch `tools/test-lock.json`** — neither by hand nor with `pnpm test:lock --update`. If a locked test has to change, say so; the user re-locks it.
- **Explain things once.** Don't narrate an explanation while editing and then repeat it in the summary.
- Package manager is **pnpm** — never npm or yarn.
- **Never write a user-facing text in any language other than Spanish.** See [i18n](#i18n).
- `CHANGELOG.md` is generated by semantic-release — never hand-edit.

## Layout

pnpm workspace monorepo. Package-scoped scripts run as `pnpm --filter @chesspecker/<web|api> <script>`; each `package.json` lists them.

- `apps/web` (`@chesspecker/web`) — Angular 22 (standalone components, signals), `@ngrx/signals` stores, RxJS, IndexedDB via `idb`, Vitest through Angular's native builder.
- `apps/api` (`@chesspecker/api`) — NestJS + MikroORM + Postgres.
- `libs/api-definitions` (`@chesspecker/api-definitions`) — the shapes crossing the HTTP boundary: requests, responses, state unions, route table and runtime Zod schemas. Import types with `import type` and schemas as value imports.

## Code style

- Relative `./` / `../` imports are blocked: use the `@app/*` aliases, listed in `apps/web/tsconfig.json`.
- When in doubt, the rules are in `tsconfig.base.json` (and each package's tsconfig), `eslint.config.mjs` (file and function size limits, selectors, class suffixes), `.stylelintrc` (no literal colours, no `@import`, `::ng-deep` under `:host`) and `.prettierrc`. Lint runs with `--max-warnings 0`, so a warning fails like an error.

## Architecture

`apps/web/src/app/` is a clean-architecture-flavored split: `repository/` (data access), `use-case/` (business logic), `store/` (`@ngrx/signals`), `service/`, `directive/`, `component/`, `layout/`, `page/`, `pipe/`, `model/`, `definition/`, `util/`, `strategy/`, `guard/`, `interceptor/`, `testing/`.

The web app never calls `HttpClient` directly: `ApiSdkService` (`service/api-sdk.service.ts`) owns every request and the repositories call it. A call is `apiSdk.<VERB>.<module>(route, options)` with three named holes — `path` fills the route's `:params`, `params` is the body on writes and the query string on reads, `query` is always the query string — each required only when the route declares it. Reads are cancelled on router navigation, writes are not (`cancellable` overrides); a cancelled request rejects with `ApiCancelledError`, which stores treat as "nothing happened".

The session cookies are `httpOnly`: `SessionStore` probes `GET /auth/refresh-session` on startup and treats a 401 as "logged out".

## i18n

`es-ES` is the source language. Every other language, English included, is translated by a professional translator through `pnpm i18n:export` / `pnpm i18n:import` — never by hand, never by the agent. Create a key with `pnpm i18n:add --name <NAME> --text <text>` (`--scope`, default `common`; `--plural <param>` with one flag per form instead of `--text`): it writes the ULID, the Spanish text and an empty slot for every other language. Never run `i18n:prune --yes`, `i18n:clear`, `i18n:export` or `i18n:import` unless asked.

Before doing anything else with translations (plurals, selects, gender, using keys in templates, any other `i18n:*` command), read the sections _The catalogue_, _Messages_ and _Commands_ of `node_modules/@drackp2m/transloco-ulid-cli/README.md`, and `docs/agents/i18n.md` for what is specific to this repo.

## Gotchas

- A `define` inside a configuration of `apps/web/angular.json` replaces the one in `options` — it is not merged — so a new constant must be repeated in `configurations.development` or it is missing under `ng serve` only.
